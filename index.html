Política de Privacidad

Información sobre el tratamiento de datos de la extensión de Chrome SSOF OCC · Operaciones.

Uso interno autorizado   Fecha de entrada en vigor: 7 de septiembre de 2026

1. Ámbito y responsable

Esta Política de Privacidad describe cómo la extensión de Chrome SSOF OCC · Operaciones trata la información necesaria para proporcionar acceso autenticado y autorizado a sus funciones operativas ferroviarias.

La extensión está destinada exclusivamente a usuarios autorizados. Para consultas relacionadas con privacidad o ejercicio de derechos, el usuario puede utilizar el correo de contacto del desarrollador publicado en la ficha oficial de SSOF OCC · Operaciones en Chrome Web Store.

2. Finalidad del tratamiento

SSOF OCC · Operaciones utiliza los datos únicamente para:

  • autenticar al usuario;
  • verificar si dispone de autorización operativa;
  • mantener de forma segura una sesión autenticada;
  • rosterizar y gestionar trenes dentro del flujo operativo SSOF;
  • consultar y procesar información ferroviaria de GTrenes/ADIF necesaria para la interfaz H24/OCC;
  • bloquear o permitir el uso según el estado de autorización asignado por SSOF Identity.
Los datos no se utilizan para publicidad, marketing, perfilado comercial, evaluación crediticia ni finalidades ajenas a la operación ferroviaria de SSOF.

3. Categorías de datos tratadas

3.1 Información de identificación personal

SSOF trata la dirección de correo electrónico utilizada para identificar la cuenta del usuario y asociarla con su autorización operativa.

3.2 Información de autenticación

La extensión permite al usuario introducir sus credenciales para autenticarse mediante Firebase Authentication.

SSOF no almacena la contraseña del usuario en texto plano. La contraseña se transmite al servicio de autenticación únicamente cuando es necesaria para iniciar sesión. Tras una autenticación válida, la extensión gestiona los tokens de sesión necesarios para mantener la sesión y renovarla de forma segura.

3.3 Información operativa procedente de GTrenes/ADIF

Cuando el usuario está autorizado, SSOF puede consultar y procesar información ferroviaria mostrada o devuelta por GTrenes/ADIF necesaria para la identificación y rosterización de trenes, estado operativo, estaciones y recorrido, horarios, tiempos, retrasos, adelantos y otros datos necesarios para H24/OCC.

SSOF no utiliza este acceso para recopilar el historial general de navegación del usuario.

4. Autenticación y autorización

La identidad del usuario se autentica mediante Firebase Authentication. El derecho de uso de SSOF se decide de forma independiente mediante el backend SSOF Identity.

  • ACTIVE: acceso permitido.
  • PENDING: acceso pendiente.
  • SUSPENDED: acceso suspendido.
  • REVOKED: acceso revocado.

La existencia de una cuenta autenticada no garantiza por sí sola el derecho de uso de SSOF.

5. Almacenamiento local y sesión

La extensión utiliza almacenamiento propio de Chrome para conservar únicamente la información necesaria para su funcionamiento, incluyendo estado operativo local, datos ROSTER y datos de sesión.

Los tokens de autenticación se gestionan dentro del contexto protegido de la extensión. No se utilizan cookies publicitarias ni mecanismos de seguimiento comercial.

6. Servicios y proveedores técnicos

SSOF utiliza servicios técnicos de Google/Firebase para prestar su funcionalidad:

  • Firebase Authentication / Identity Toolkit, para autenticar usuarios;
  • Secure Token Service, para renovar sesiones autenticadas;
  • Cloud Functions, para consultar SSOF Identity y determinar el estado de autorización.

La extensión también interactúa con el servicio corporativo GTrenes/ADIF cuando el usuario dispone de una sesión válida y está autorizado para operar.

7. Código remoto

SSOF OCC · Operaciones no descarga ni ejecuta JavaScript o WebAssembly remoto.

Todo el código ejecutable está incluido en el paquete distribuido a través de Chrome Web Store. Las comunicaciones HTTPS con Firebase, Cloud Functions y GTrenes/ADIF son intercambios de datos con servicios backend y no implican la descarga de código ejecutable remoto.

8. Compartición y venta de datos

  • SSOF no vende datos de usuario.
  • No utiliza datos para publicidad personalizada.
  • No transfiere datos para finalidades ajenas a la finalidad única de la extensión.
  • No utiliza datos para determinar solvencia, situación crediticia ni ofrecer préstamos.
  • No crea perfiles comerciales de los usuarios.

Los datos solo se comunican a los proveedores técnicos necesarios para autenticación, autorización y funcionamiento operativo, en la medida necesaria para prestar el servicio.

9. Retención

Los datos almacenados localmente por la extensión se mantienen únicamente mientras sean necesarios para proporcionar la funcionalidad operativa o conservar una sesión válida. El cierre de sesión elimina la sesión operativa local correspondiente.

La información de autorización administrada por SSOF Identity puede mantenerse mientras la cuenta exista y sea necesaria para gestionar el derecho de acceso, auditoría y seguridad del sistema.

10. Seguridad

SSOF aplica un modelo de acceso fail closed: si no es posible confirmar una autorización válida, la funcionalidad operativa permanece bloqueada.

La autorización se verifica mediante backend y no depende de una lista de usuarios incluida en la extensión. PENDING, SUSPENDED y REVOKED bloquean el acceso operativo. Una revocación confirmada interrumpe el derecho de uso aunque la sesión de autenticación continúe existiendo.

11. Derechos y consultas

Para cualquier consulta sobre privacidad, acceso, rectificación o eliminación de información asociada a la cuenta SSOF, el usuario puede dirigirse al desarrollador mediante la información de contacto publicada en la ficha oficial de SSOF OCC · Operaciones en Chrome Web Store.

Las solicitudes se gestionarán conforme a la normativa aplicable y a las obligaciones de seguridad y conservación que correspondan.

12. Cambios en esta política

Esta Política de Privacidad puede actualizarse cuando cambien las funciones, los proveedores técnicos o los requisitos legales y de Chrome Web Store. La versión vigente estará disponible permanentemente en la URL de Política de Privacidad indicada en la ficha de Chrome Web Store.
